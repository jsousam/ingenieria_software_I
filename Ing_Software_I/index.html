Actividades del Personal en el Desarrollo de Software

Investigación sobre las fases del ciclo de vida del software (SDLC), el personal involucrado y sus entregables principales.

1. Obtención de Requerimientos

Fase inicial donde se capturan las necesidades del usuario final y del negocio para definir qué debe hacer el sistema.

  • Personal encargado: Analista de Negocio (Business Analyst), Product Owner.
  • Actividades: Entrevistas, reuniones con stakeholders y encuestas.
  • Entregable principal: Documento de visión y Backlog de requerimientos.

Reunión de toma de requisitos.

2. Análisis de Requerimientos

Modelado y estructuración de los requisitos recolectados para asegurar que sean viables y sin contradicciones.

  • Personal encargado: Analista de Sistemas, Arquitecto de Software.
  • Actividades: Clasificación de requisitos funcionales/no funcionales y diagramación UML.
  • Entregable principal: Especificación de Requerimientos de Software (ERS / SRS).

Modelado de requisitos.

3. Diseño del Software

Definición de la arquitectura técnica, base de datos e interfaz de usuario previa a la codificación.

  • Personal encargado: Arquitecto de Software, Diseñador UX/UI, DBA.
  • Actividades: Diseño de base de datos, diagrama entidad-relación y prototipado.
  • Entregable principal: Documento de Arquitectura (SAD) y maquetas navegables.

Diseño de arquitectura e interfaz.

4. Desarrollo y Codificación

Traducción de los documentos de diseño en código fuente funcional mediante lenguajes de programación.

  • Personal encargado: Programadores / Desarrolladores (Frontend, Backend).
  • Actividades: Programación de módulos, consumo de APIs y control de versiones con Git.
  • Entregable principal: Código fuente estructurado e incrementos del sistema.

Construcción del sistema.

5. Pruebas y Aseguramiento de Calidad (QA)

Proceso de validación para detectar fallos, errores de rendimiento o vulnerabilidades antes de la entrega.

  • Personal encargado: Ingeniero de QA, Tester de Software.
  • Actividades: Pruebas funcionales, unitarias, de integración y reporte de bugs.
  • Entregable principal: Reporte de pruebas y matriz de bugs corregidos.

Ejecución de pruebas de calidad.

6. Despliegue o Puesta en Marcha

Instalación y publicación del sistema en servidores de producción para el acceso de los usuarios finales.

  • Personal encargado: Ingeniero DevOps, Administrador de Sistemas.
  • Actividades: Configuración de servidores, despliegue de base de datos y capacitación.
  • Entregables: Sistema publicado en entorno real y manuales de usuario.

Puesta en producción.

7. Mantenimiento del Software

Soporte continuo tras la entrega para garantizar la estabilidad y adaptar el software a nuevas necesidades.

7.1. Mantenimiento Correctivo

Corrección de errores o fallas reportadas por los usuarios durante el uso diario.

7.2. Mantenimiento Preventivo

Revisiones y optimizaciones internas para evitar futuros fallos del sistema.

7.3. Mantenimiento Adaptativo

Ajustes para que el sistema funcione con nuevos sistemas operativos, navegadores o cambios normativos.
