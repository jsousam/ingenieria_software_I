Metodología de Búsqueda e Investigación

Este sitio compila las actividades clave del equipo en el ciclo de vida del desarrollo de software (SDLC). La información fue recabada mediante búsquedas web y sustentada con literatura académica de repositorios como Redalyc, PMBOK y RUP.

1. Obtención de Requerimientos (Elicitación)

Fase inicial donde se identifican las necesidades del cliente y usuarios finales para definir las capacidades del sistema.

  • Personal clave: Analista de Negocio (Business Analyst), Product Owner.
  • Actividades principales: Entrevistas, talleres con stakeholders, encuestas y observación directa de procesos.
  • Entregables: Documento preliminar de visión del producto y backlog de requerimientos.

Entrevistas y talleres de elicitación.

2. Análisis de Requerimientos

Refinamiento y modelado de los requisitos para eliminar ambigüedades, resolver inconsistencias y validar la factibilidad técnica.

  • Personal clave: Analista de Sistemas, Arquitecto de Software.
  • Actividades principales: Clasificación de requisitos funcionales y no funcionales, elaboración de diagramas UML y Casos de Uso.
  • Entregables: Especificación de Requerimientos de Software (SRS / ERS).

Estructuración y especificación técnica.

3. Diseño del Software

Definición de la arquitectura del sistema, esquemas de datos, componentes e interfaces gráficas antes de la codificación.

  • Personal clave: Arquitecto de Software, Diseñador UX/UI, Administrador de Base de Datos (DBA).
  • Actividades principales: Selección del stack tecnológico, diseño de bases de datos, diagramas ER y prototipos interactivos.
  • Entregables: Documento de Arquitectura (SAD) y maquetas navegables.

Prototipado visual y modelado arquitectónico.

4. Desarrollo del Software (Codificación)

Construcción del sistema traduciendo los documentos de diseño en código fuente ejecutable, seguro y limpio.

  • Personal clave: Programadores y Desarrolladores (Frontend, Backend, Fullstack).
  • Actividades principales: Programación, control de versiones (Git), integración de servicios web (APIs) y pruebas unitarias.
  • Entregables: Código fuente versionado e incrementos funcionales.

Implementación de módulos y lógica de negocio.

5. Pruebas y Aseguramiento de la Calidad (QA)

Verificación técnica para garantizar que el software opere sin fallos y cumpla con las especificaciones del cliente.

  • Personal clave: Ingeniero de QA, Tester de Software (QA Manual / Automation).
  • Actividades principales: Diseño y ejecución de casos de prueba (funcionales, integración, rendimiento y seguridad).
  • Entregables: Reporte de hallazgos (bugs), matriz de cobertura y certificación de calidad.

Ejecución de pruebas y control de calidad.

6. Despliegue o Puesta en Marcha

Instalación y liberación del software en el entorno de producción para su uso operativo final.

  • Personal clave: Ingeniero DevOps, Administrador de Sistemas / Nube.
  • Actividades principales: Configuración de servidores, automatización de despliegues (CI/CD), migración de datos y capacitación.
  • Entregables: Aplicación alojada en producción y manuales operativos.

Puesta en producción y gestión de infraestructura.

7. Mantenimiento de Software

Fase posterior a la entrega enfocada en preservar la operatividad, optimizar componentes y resolver incidencias.

7.1. Mantenimiento Correctivo

Diagnóstico y resolución de errores o fallos detectados por los usuarios en el entorno real de producción.

7.2. Mantenimiento Preventivo

Refactorización de código e intervenciones técnicas para prevenir incidentes futuros y mejorar la mantenibilidad.

7.3. Mantenimiento Adaptativo

Modificaciones para ajustar la aplicación a cambios en el entorno (actualización de SO, navegadores, hardware o leyes).
